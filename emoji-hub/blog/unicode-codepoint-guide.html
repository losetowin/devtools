emoji Unicode 码点查询指南：U+1F600 怎么看、怎么用、怎么复制

Emoji 大全 · 2026-09-13

每个 emoji 在 Unicode 标准里都有一个唯一编号，写作 U+XXXXXX，例如 😀 是 U+1F600。看懂这个编号，你就能在任何编程语言、数据库、前端代码里精确引用一个表情，而不只是复制粘贴。本文讲清码点怎么读、怎么换算、怎么用。

U+1F600 是什么意思

U+ 是 Unicode 的固定前缀，后面跟一个十六进制（Hex）数字。U+1F600 拆开看：

  • U+：表示「Unicode 码位（code point）」
  • 1F600：十六进制编号，换算成十进制是 128512
  • 含义：它是 Unicode 标准里第 128512 个被收录的字符

emoji 大多分布在 U+1F300 ~ U+1FAFF 区间（叫「补充多文种平面」SMP），所以常见 emoji 码点都长得像 U+1F600、U+1F389、U+2764 这样。

为什么有的 emoji 是两个码点

注意上表的 ❤️：它其实是 U+2764（黑色爱心符号）+ U+FE0F（变体选择符 VARIATION SELECTOR-16）。U+FE0F 的作用是「请用彩色 emoji 样式显示我」。少了它，有些系统会把 ❤ 显示成黑白符号 ❤。国旗、家庭、肤色 emoji 同理，由多个码点拼接（中间用零宽连接符 U+200D 连接）。

在代码里怎么用码点插入 emoji

JavaScript

// U+1F600 用 \u{} 表示
const face = "\u{1F600}";   // 😀
console.log(face);

// 老语法不支持 {}，要写代理对
const face2 = "\uD83D\uDE00"; // 同样是 😀

Python

face = "\U0001F600"   # 注意是大写 U + 8 位十六进制
print(face)          # 😀
# 反向查询
print(hex(ord("😀"))) # 0x1f600

HTML

&#x1F600;  →  😀
&#128512; →  😀   （十进制写法）

UTF-8 字节长度怎么算

码点本身只是一个数字，落到磁盘上要用 UTF-8 编码。规则很简单：

码点范围UTF-8 字节数
U+0000 ~ U+007F1 字节
U+0080 ~ U+07FF2 字节
U+0800 ~ U+FFFF3 字节
U+10000 ~ U+10FFFF4 字节

所以 😀（U+1F600）在 UTF-8 里占 4 个字节。这也是为什么有些旧数据库字段按「字符数」估算长度时会出问题——它其实是字节数。

怎么查一个 emoji 的码点

  1. Mac：系统自带「字符显示程序」→ 选中字符即可看到码点
  2. Windows：设置 → 时间和语言 → 表情面板
  3. 代码：ord("😀")（Python）或 "😀".codePointAt(0).toString(16)（JS）
  4. 在线工具：直接在 Emoji 大全 EmojiHub 搜索表情，详情页同时显示码点、短代码和图形字符
💡 复制 emoji 时建议连「图形字符 + 码点」一起记：图形字符给人看，码点给程序用。在 Emoji 大全 每个表情页都可一键复制这两者。
