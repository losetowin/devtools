纯本地 JSON 工具，覆盖接口调试全流程：美化排版、压缩去空格、校验并定位错误行列、树形视图展开折叠、JSON5 宽松解析（支持注释与单引号）、JSONPath 查询、多段日志解析与前后对比。所有处理在浏览器本地完成，数据零上传、可离线使用。

JSON 校验报错 Unexpected token 怎么办？

常见原因：末尾多余逗号、键或字符串用了单引号、混入注释、文件带 BOM、转义字符非法。切到「校验」页会自动定位错误行列；对照 JSON 常见错误 10 种 逐一排查。

JSON 里能写注释吗？

标准 JSON 不支持注释。需要注释、单引号、尾逗号时用 JSON5（本工具默认宽松解析），详见 JSON5 与 JSON 的区别。

怎么从大 JSON 里提取指定字段？

使用「树形」页的 JSONPath 查询，如 $.store.book[?(@.price<10)].title，高亮命中节点，语法见 JSONPath 速查。

数据会上传到服务器吗？

不会。所有处理都在浏览器本地完成，页面不发送你的 JSON 内容，断网也能使用。
