JSON 常见错误 10 种：Unexpected token 等报错原因与修复方法

JSON 格式化工具 · 2026-09-13

JSON 报错几乎都来自同一个根因：不是合法 JSON 文本。下面是 10 种最高频的错误，附示例和修复方法。遇到 `Unexpected token` 时，先看报错位置，再对照本清单逐项排查。

10 种高频错误对照表

#错误特征典型报错修复
1末尾多余逗号Unexpected token }删除最后一个键值对后的逗号
2键或字符串用了单引号Unexpected token '全部改为双引号
3混入注释Unexpected token /删除 // 或 /* */（JSON 不支持注释）
4文件开头有 BOM 或空白Unexpected token以 UTF-8 无 BOM 保存
5字符串内非法转义Bad escaped character只使用 \ " / b f n r t uXXXX
6控制字符未转义（换行在字符串里）Unexpected token换行写成 \n
7值类型错误（NaN/Infinity/undefined）Unexpected token NJSON 只允许字符串/数字/布尔/null/数组/对象
8数字格式非法（前导零、.5）Unexpected number写成 0.5
9缺逗号或多逗号Unexpected string键值对之间恰好一个逗号
10括号/引号不配对Unexpected end of input用带行列提示的校验工具定位

错误示例与修复

// ❌ 错误：单引号 + 末尾逗号 + 注释
{'name': 'tom', 'age': 30,} // 用户信息

// ✅ 正确
{"name": "tom", "age": 30}

实用排查顺序

  1. 先看报错行列号指向的位置，90% 的错误就在附近
  2. 检查引号：JSON 只认双引号
  3. 检查逗号：最后一个元素后不能有逗号
  4. 检查注释与单引号（很多人把 JS 对象写法直接当 JSON 用）
  5. 用在线校验工具复验
