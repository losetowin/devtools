WiFi / 路由器密码怎么设才安全：WPA3、访客网络与常见弱密码清单

密码工坊 PassForge · 2026-09-13

家里 WiFi 一旦被蹭，轻则网速变慢，重则被接入同一局域网扫描你所有设备。这篇把 WiFi 密码、路由器管理员密码、加密方式、访客网络一次讲清，附常见弱密码黑名单。

先分清两个密码

类型作用建议长度
WiFi 密码（预共享密钥）设备接入无线网络用≥ 12 位，建议 16 位随机
路由器管理员密码登录路由器后台（192.168.1.1）改配置独立、不与 WiFi 密码重复，16 位最佳

最常见的错误是把这两个设成同一个，或者管理员密码用出厂默认（admin/admin）。路由器后台一旦暴露，攻击者改 DNS、挂钓鱼页面都易如反掌。

加密方式怎么选：WPA2 还是 WPA3

  • WPA3（推荐）：2018 年后的主流路由器都支持，抗字典攻击能力强，即使密码一般也更安全
  • WPA2-PSK AES：老设备兼容首选，禁止用 TKIP
  • WEP / WPA 个人版：已被攻破，任何情况都不要用

如果设备都新，直接选 WPA2/WPA3 混合，兼顾兼容与安全。

WiFi 密码的设置原则

  1. 长度 ≥ 12 位，能 16 位最好（参考16 位强密码指南）
  2. 不要用生日、手机号、门牌号、姓名拼音
  3. 不要用 abcd1234、12345678 这类连续键盘序列
  4. 不要把 WiFi 名（SSID）和密码设成相关，如 SSID 是 ZhangHome 密码就别用 Zhang123
  5. 设一次就写在路由器背面贴纸上，忘记了直接重置

常见弱 WiFi 密码黑名单

类型示例问题
纯数字短码12345678、88888888字典第一波就被试穿
常见词加数字password123、wifi123456彩虹表全覆盖
键盘序列qwertyuiop、asdfghjkl机器按坐标生成
个人信息姓名拼音+生日社交媒体一搜就有
默认密码admin、root、空密码出厂没改

开访客网络

家里来客人，不要把主 WiFi 密码给出去。在路由器后台开 访客网络（Guest Network）：

  • 单独的 SSID 与密码，定期更换
  • 与主网络隔离，客人看不到你的 NAS、打印机、智能家居
  • 设置上网时长或带宽限制

其他值得顺手关的设置

  • 关闭 WPS：WPS 8 位 PIN 码几小时就能跑穿，不用就关
  • 关闭远程管理：路由器后台不要暴露到公网
  • 隐藏 SSID 意义不大：无线探测依然能发现，徒增连接麻烦，不如把密码设强
  • 定期升级固件：厂商会修补安全漏洞，一年至少更一次

忘了 WiFi 密码怎么办

不用紧张：路由器背面一般有重置键，长按恢复出厂，然后用随机密码工具重新设一套。Windows 上已连接过的网络可在「网络设置 → WLAN → 管理已知网络」查看；Mac 在「钥匙串访问」里搜 SSID。

⚠️ 千万别把 WiFi 密码设成「全家姓名首字母 + 门牌号」这种规则，例如 Zhsr201!。攻击者拿到你家 SSID 或者从快递面单看到姓氏，三次尝试就能猜到。
💡 WiFi 密码不需要天天换，但建议 1~2 年换一次。用 在线随机密码生成器 选 16 位、含大小写+数字+符号，生成后抄到贴纸上即可，WiFi 密码不需要「好记」。
